# Data

The 460 photographs (4000 x 3000 px, ten per calibration level) are not stored
in this repository because of their size (2.3 GB). They are available from the
corresponding author upon reasonable request.

Unpack them so that each analyte has its own folder here:

    data/glu/   glu=<level>_<index>.jpg
    data/Mg/    mg=<level>_<index>.jpg
    data/Cl/    cl=<level>_<index>.jpg
    data/pH/    pH=<level>_<index>.jpg
    data/urea/  ur=<level>_<index>.jpg

Alternatively pass --data-root or set SWEAT_DATA_ROOT to an existing copy.
